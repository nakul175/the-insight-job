## C2 design delta (proposed)

Bootstrap a Django 5.2 LTS modular monolith with server-rendered accessible HTML and PostgreSQL-ready persistence. Django provides password verification, session rotation, CSRF protection and logout. No custom tokens or model inference. SQLite is local/test only. This keeps the initial identity boundary inspectable while later collection workers can be separated.

Workspace has UUID identity; Membership has a unique user/workspace pair. All product workspace reads and selection writes resolve through current membership. Staff status does not bypass it. Unknown and inaccessible IDs share a generic 404, with no foreign names, IDs or counts. Selection is POST-only, CSRF-protected and records actor/time/workspace; it locks the membership row while writing its audit record. Future record queries must scope by authorised workspace before fetching data or aggregates. There are no content records in this increment.

A one-hour server-side session expires without replaying an action. Reauthentication always leads to workspace selection, ignoring next destinations. Logout is POST-only, clears the session, and protected pages use no-store. Membership revocation applies to the next request. A selection is convenience state, never an authorization token.

S01 includes signed-out, invalid credentials, expired session notice, assigned-workspace list, no-membership recovery guidance, unavailable workspace and signed-out states; semantic inputs, keyboard focus and a 360px layout. The workspace landing clearly states that collection/processing are not available. No fake data or fake working controls.

Migration: initial new tables only. No existing user data. Recovery before a live release is to retain the database and roll application code back; destructive migration reversal requires explicit review. No background jobs or external writes.
