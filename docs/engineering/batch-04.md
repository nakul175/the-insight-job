## Implementation and verification

Systems start Draft with stable IDs, scoped owner and purpose. Configuration snapshots validate permitted sources, published type keys, explicit Unknown behavior and literal relevance criteria/examples. Unselected source grants and pending work are stopped; revoked grants are not silently restored. Copies retain only non-sensitive logic, no source/type grants, dependency IDs, destination or secrets. Required schema/rules/destination activation gaps remain visible; execution publication is owned by later stories.

Evaluation sets retain immutable label versions pinned to content and processing revisions, plus expected routing/qualification labels. Schema checks evaluate fields only (the UI says routing/qualification are not yet evaluated); full expected keys, required values and JSON-compatible types are checked. Passing current-label checks gate current-draft publication. Breaking changes list blocking system/pending-extraction dependencies. Retirement preserves historical definitions and blocks new selection/drafts.

Enrichment policies pin exact domains and explicit depth/page/time/byte/media/provider limits. Only HTML/PDF collection is supported; media duration/provider spend are zero. An authorised trigger schedules one collection job at a time through the existing source connection/scope/worker checks. `run_enrichments --limit 20` advances coverage and schedules the next page; `run_collections --once` or its existing worker executes captures. Repeated ticks are intentional. Coverage retains attempted URL, parent record/capture, source run, missing reasons and acquired capture IDs; unresolved field labels remain until later final qualification. Seeds, visited links and redirect targets are deduplicated. No-links proceeds to final validation without a fetch.

Aggregate page/time/byte caps constrain successive jobs. A failed transfer without a retained byte count conservatively charges its remaining byte allocation, explicitly labelled reserved/uncertain rather than acquired bytes; this can stop early and requires review/raising a cap. Fetches honor remaining byte/time budgets as well as baseline hard limits. New attempts after an authorised cap increase retain usage, visited/pending links and provenance, superseding the old attempt. Current parent and evidence-source permissions are checked before consuming retained capture HTML, not just before fetching. Workspace mutation locks serialize supported source revocation paths. Blocked attempts need explicit owner review; they are not automatic successes.

Destination registration stores type, endpoint, scoped owner/system and opaque secret reference. Only declared sandbox HTTP contract testing is available: synthetic contract validation sends nothing and explicitly leaves reachability unverified. Credential references block testing because secret resolution/verification is unavailable; no production record is sent and system activation remains gated.
