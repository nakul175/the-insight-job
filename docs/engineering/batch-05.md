## Implementation and limits

SystemResult pins immutable source content, processing revision, classification version, system configuration and system schema. Its unique key includes all those processing/classification pins so replay of the same event is idempotent while source/parser/type changes get fresh results without silently inheriting old overrides. Multi-system previews use separate transactions and report each failure independently. Required field gaps remain Review/Enrich; hard failures stop that system. Compatible completed common/type extraction can be reused only under the same source/analysis/classification and matching field type/unit/instruction, retaining original candidates and job/schema lineage.

Relevance retains literal criteria/examples, matched evidence, type/Unknown policy and source/configuration pins. Semantic inference is unavailable, not fabricated. Qualification drafts validate field/operator/value/group/unknown policy, retain per-rule inputs/reasons/evidence/version and apply explicit all/any groups. All typed date comparisons use timezone-aware instants, including equality; naive dates Review. ISO timestamp extraction preserves offsets. Units/currencies must match exactly; no conversion provider exists. Operators explicitly distinguish strict/inclusive boundaries.

Corrections retain old/new value, pinned segment, actor/reason and rerun rules.
