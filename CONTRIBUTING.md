# Contributing

Read root/nested agent instructions and the approved repository profile. Link a real work item and source requirement/engineering authorisation. Use a focused branch and a proportionate implementation plan. Preserve existing architecture and unrelated work.

Run the actual reviewed engineering commands, update canonical docs/traceability and use the PR template. Required independent owner review applies to human and AI-generated code. Missing commands, failures, incomplete features and unavailable connectors must remain explicit.

Do not add secrets, protected data, unapproved dependencies/providers or untracked changes to permissions and configuration. Merge, deploy and live data operations require separate authority. See the pinned package for the full rules and exception process.
